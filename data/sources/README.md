# Local source documents

Place approved PDFs or saved HTML snapshots here. Sources and generated
`*.metadata.json` sidecars are ignored by Git.

Organise sources by retrieval category:

```text
data/sources/
├── finance/
├── finance_operations/
├── student_admin/
└── digital_learning/
```

Do not add credentials, confidential files, or documents you cannot process.
Public access does not automatically permit redistribution.
